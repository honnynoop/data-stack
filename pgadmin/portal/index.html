PostgreSQL 연결 & 차트 생성 순서

  1. 1localhost:8088 접속 → admin / admin 로그인
  2. 2상단 Settings → Database Connections → + Database
  3. 3유형 PostgreSQL 선택 후 URI 입력:
    postgresql+psycopg2://airflow:airflow@postgres:5432/airflow
  4. 4Test Connection → "Connection looks good!" → Connect → Finish
  5. 5Datasets → + Dataset · Database: airflow · Schema: marts · Table 선택 후 저장
  6. 6Charts → + Chart → Dataset 선택 → 차트 유형 선택 → 생성
  7. 7Dashboards → + Dashboard에 차트 드래그&드롭

Quick Queries — pgAdmin에서 복사 실행
📊 월별 매출 요약
SELECT
  year_month,
  SUM(total_revenue)     AS 매출,
  SUM(order_count)       AS 주문수,
  SUM(unique_customers)  AS 구매고객,
  ROUND(AVG(gross_margin_rate),1) AS 이익률
FROM marts.monthly_sales
GROUP BY year_month
ORDER BY year_month;
👥 고객 RFM 등급 분포
SELECT
  customer_grade   AS 등급,
  COUNT(*)           AS 고객수,
  ROUND(AVG(rfm_total),1) AS 평균RFM,
  ROUND(AVG(lifetime_value),0) AS 평균LTV
FROM marts.dim_customers
GROUP BY customer_grade
ORDER BY 평균LTV DESC;
🏷️ 카테고리별 매출·마진
SELECT
  category,
  COUNT(*)             AS 주문수,
  SUM(revenue_amount)  AS 총매출,
  SUM(gross_profit)    AS 총이익,
  ROUND(AVG(
    gross_profit::numeric
    /NULLIF(revenue_amount,0)
  )*100,1)             AS 마진율
FROM marts.fct_orders
WHERE is_revenue = true
GROUP BY category
ORDER BY 총매출 DESC;
📣 채널별 ROAS / CAC
SELECT
  channel          AS 채널,
  SUM(total_spend)  AS 총광고비,
  SUM(new_customers)AS 신규고객,
  ROUND(AVG(roas),2) AS 평균ROAS,
  ROUND(AVG(cac),0)  AS 평균CAC
FROM marts.marketing_roi
GROUP BY channel
ORDER BY 총광고비 DESC;
